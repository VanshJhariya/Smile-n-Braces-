# Smile 'N' Braces: website

Open `index.html` in a browser, or upload the whole folder to any static host.

```
index.html            structure and copy
css/styles.css        styling and animation (numbered sections)
js/main.js            treatment finder, live opening hours, scroll motion
assets/images/
  doctor/             Dr. Sumit Jain portrait
  team/               team photo
  clinic/             clinic interior photos used in the gallery
  unused/             photos that show patients: get written consent before using them
```

Edit finder content in `CONCERNS` and opening hours in `HRS`, both in `js/main.js`.
Phone numbers are in `index.html` and `js/main.js`.
